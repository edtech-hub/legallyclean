# Legally Clean: pitch prototype

Static prototype for legallyclean.com (post-construction and commercial cleaning, South Florida), built by White Phoenix.
Live: https://legallyclean.whitephoenixconsulting.com (noindex).

- Pages are generated: `python3 tools/build_site.py .`
- Images: `cd tools && npm install`, then `node tools/images.js images.json` (sources are not committed).
- Design: WordPress core blocks on Twenty Twenty-Four tokens and patterns. Playbook: ~/projects/pitch-prototypes/CLAUDE.md
